Legal Site Conversion Playbook

The reusable, any-state process for converting a law firm's website to our Astro/Cloudflare platform. The build machinery is the same as our dental/general conversions (docs/site-conversion-playbook.md, the convert-site skill) — this layers on the legal-specific schema, content, directories, and the part that makes legal hard: a state-agnostic compliance engine, because bar advertising rules vary by state and a mistake can get the client sanctioned.

⚠️ We are not lawyers and this is not legal advice. This playbook produces a compliant-by-default draft and a checklist, but a licensed attorney in every state the firm practices in or advertises into must review and sign off before go-live. Bar rules change; always pull the current version (§3 process).

0 · When to use

Any law-firm conversion: /convert-legal-site <url>, "build a site for <firm>", "port this attorney/law firm to our platform". Works for any practice type (PI, family, criminal, estate, business) in any US state. First reference build: Parian Lawyers (PI, GA + AL) — see specs/customers/parian-lawyers-conversion.html.

2 · The state-agnostic compliance engine (the core)

Don't hardcode one state's rules. For every firm, run this fixed set of compliance dimensions against the firm's state(s). The dimensions are universal; the answers are looked up per state (§3). Each dimension that applies becomes a build requirement.

#Dimension — ask of each state's rulesTypical output
1Contingency/"no fee unless you win" disclaimer required? Exact mandated wording?Verbatim disclaimer, equal prominence, wherever fee claims appear
2Past-results / case-results disclaimer required?"Prior results do not guarantee a similar outcome" + tie to specific facts
3Testimonial / endorsement disclosure rules?Real + permissioned; disclose paid/portrayed
4"Specialist / expert / certified" restricted?Ban those terms unless board-certified; use "experienced/focused on"
5"Attorney Advertising" / "Advertisement" label required?Footer label (include by default for multi-state safety)
6Responsible-attorney name & office disclosure required?Named lawyer + a bona-fide office city/address in footer
7Trade-name restrictions? (no gov't implication, not misleading)Validate the firm's trade/dba name
8Solicitation limits? (anti-30-day accident mail, targeted-mail filing, live-contact bans)Constrain outreach/lead automation; never solicit fresh accident victims
9Ad pre-filing / bar submission required?A few states require filing ads with the bar — flag for counsel
10Record-retention period for ads?Retain site snapshots N years (e.g. GA = 2)
11Comparative/superlative & awards substantiation? ("best", ratings)Drop unverifiable superlatives; name the rating org + criteria
12Multi-state: serves/advertises into other states?Apply each state; "not licensed in <state>" disclosure if no bar admission there; referral disclosure if cases referred out
Multi-state rule of thumb: a firm is bound by the advertising rules of every state it solicits or advertises into, not just where it's licensed. Resolve conflicts to the strictest applicable rule.

3 · How to fill the engine for a given firm (the research step)

  1. Identify the jurisdictions: state(s) of licensure (from the attorneys' bar admissions) + every state in the firm's advertised service area. That's the compliance set.
  2. Pull current rules per state. For each, web-research the state's Rules of Professional Conduct 7.1–7.5 (advertising/solicitation). Authoritative sources: the state bar's official rules page, then secondary summaries (Lawyer Legion per-state pages, the state AG). Answer all 12 dimensions. Capture exact mandated disclaimer wording where it exists (states differ — don't paraphrase).
  3. Build the per-firm compliance matrix (12 dimensions × each state) and turn every "required" into a concrete build task + a checklist row.
  4. Inject disclaimers from the matrix into the footer + relevant pages (§4 library).
  5. 🚦 HUMAN GATE — counsel sign-off. Send the firm's licensed attorney (per state) the compliance matrix + the rendered disclaimers for approval before cutover. This gate is non-negotiable.

Re-run the research at each new build (rules change — e.g. Alabama overhauled its ad rules effective 1/1/2026). Never reuse a cached ruleset older than the current build.

5 · Review engine for lawyers (stricter than dental)

  • Ask only past clients — permitted in most states. Never incentivize, pay, gift, or run contests/quotas for reviews (bar + Google + FTC violation; a firm lost all its reviews over a review contest).
  • Never draft the review or tell the client what to write.
  • Confidentiality in responses: never confirm representation or reveal case details in a public reply — that's an ethics breach. Keep responses generic and gracious.
  • Keep the compliant private-feedback path for unhappy clients (no gating of public reviews) — same standard as our dental review-funnel fix.
