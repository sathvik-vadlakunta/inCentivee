Local Citations / NAP — Implementation

Make every customer's Name/Address/Phone consistent and present across the directories AI engines pull from, on autopilot, and surface a NAP-consistency score in the one weekly report. Builds on the BrightLocal R4 scaffold we already shipped.

Owner: Kody · Status: Spec (ready to build) · 2026-06-17 · pairs with specs/active/geo-levers-ops-plan.html

0. Why (verified) + what we already have

For local AI queries the top citation sources are the business's own site (~58%) + consistent directory/NAP presence (BrightLocal). This is the most automatable lever — a citation platform does ~90% on autopilot.

Already shipped (R4 scaffold):

  • geo_agent/brightlocal_client.py — track_citations(db, customer_id) (guarded; no-ops until configured). HAVE
  • citations table — directory, listed, nap_match, url_correct, listing_url, last_checked. HAVE
  • Weekly report "Local listings health" section + score (renders when citations has data). HAVE
  • Integration test wired (/api/customer/<id>/integrations/brightlocal/test) + brightlocal integration config (location_id). HAVE

So the remaining work is real account setup + wiring the actual BrightLocal API + the build/monitor workflow.

1. Tool decision — BrightLocal

Use BrightLocal (reuse the R4 scaffold). It has both halves we need + an API:

  • Citation Tracker / Local Search Audit — audits where the business is listed + flags NAP inconsistencies. → fills our citations table.
  • Citation Builder — builds/submits missing citations to aggregators + niche dirs. → the "do the work" half.
  • API — programmatic location create + audit fetch, so PracticeRank pulls results automatically.

Alternative: Moz Local (~$129/yr/location, simpler auto-sync, fewer niche dirs). Recommend BrightLocal because we've already scaffolded it and it does building + vertical directories. Cost: platform ~$39–49/mo (shared) + Citation Builder ~$2–4/citation.

2. The canonical NAP (single source of truth)

Everything keys off one canonical record per customer — we already store it on customers:

name, address, city, state, zip, phone, domain

Add a NAP lock step at onboarding: confirm the exact legal name + display name, the exact address format, and the primary tracking-free phone. Store canonical strings; nothing downstream may vary from these.

Order-of-operations (ties to the score warnings): Google Business Profile must be verified first — it's the anchor every directory and AI cross-checks. Don't build citations against an unverified/incorrect GBP.

Cost (per customer/mo)

~$12–18 platform (amortized) + one-time Citation Builder (~$2–4 × missing dirs) + one-time VA ~$20–60. Ongoing ~$12–18/mo — the cheapest lever.

7. …and how Lever A (digital PR) gets automated — the handoff

Lever A is subcontracted (white-label per-placement / The AEO Collective off-site-mentions), but PracticeRank automates the handoff + the loop:

  1. Auto-brief: monthly job → Claude drafts a newsworthy local angle + press-release/HARO-pitch draft from the customer's verified facts (reuse the content generator's "never fabricate" guardrails).
  2. Auto-order: create the order with the white-label provider — via their API if available, else auto-email/Zapier the brief to the subcontractor; store an order id.
  3. Auto-track the loop: when a placement lands, the URL shows up in our grounded AI runs' "sources now citing you" — tie placements to citations, so we double down on outlets AI actually cites and report "N earned mentions this month."

So we don't build the PR labor — we automate brief-generation, order-creation, and attribution; the provider does the outreach. Spec that as its own small build after Lever B lands.
