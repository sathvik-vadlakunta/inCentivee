What the plugin does:
  • Injects JSON-LD schema markup (LocalBusiness, FAQ, Service) into every page
  • Serves /llms.txt and /llms-full.txt for AI search engine discoverability
  • Optimizes robots.txt with AI crawler rules (ChatGPT, Claude, Perplexity, etc.)
  • Accepts content pushes (blog posts, pages) via secure REST API
  • Works with WordPress 5.6+ (requires REST API and Application Passwords)
  • Compatible with Yoast SEO, RankMath, and All in One SEO
