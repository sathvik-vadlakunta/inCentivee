Landing Page Report Tracking + Admin Viewer

Status: Spec  |  Priority: P1  |  Created: June 5, 2026

Goal: Every audit report generated on practicerank.ai should be stored, tracked, and viewable from the admin dashboard. Currently, reports are generated by the Cloudflare Worker, returned to the browser, and emailed — but the full report JSON is never saved. The admin can see leads (name, email, score) but cannot view the actual report content. This spec adds full report persistence and a report viewer in the dashboard.

Current State

Data Flow Today

User submits URL on practicerank.ai | v CF Worker (practicerank-api) 1. Scrapes website 2. Fetches Google Places data 3. Calls Claude API for audit 4. Validates + corrects report 5. Saves LEAD SUMMARY to KV <-- only score, grade, exec summary 6. Emails full report to user 7. Returns full JSON to browser | v Browser renders report Full report JSON is LOST after this

What's Missing

  • Full report JSON (all 6 category scores, findings, recommendations, competitor data)
  • Report viewer in the admin dashboard
  • Link between a practicerank.ai lead and an existing dashboard customer
  • Report history (how many reports generated, when, score trends)
  • Ability to re-send or share a report

Architecture

Design Principles

  • Zero new infrastructure — use existing KV storage (worker) and SQLite (dashboard)
  • Worker stays fast — report save is non-blocking, does not slow down the user response
  • Dashboard pulls, not pushes — dashboard syncs reports from the worker API on demand (no webhook complexity)
  • Full report preserved — store the complete validated JSON, not a summary

Data Flow (New)

User submits URL on practicerank.ai | v CF Worker (practicerank-api) 1-4. Same as today 5. Save LEAD SUMMARY to KV (unchanged) 6. Save FULL REPORT JSON to KV <-- NEW (key: report_{leadId}) 7. Email full report to user 8. Return full JSON to browser | v Admin Dashboard - New /reports page lists all reports (synced from KV) - Click to view full rendered report - Link reports to existing customers - Track report count + score trends per customer

Phase 1: Store Full Reports in Worker

1A. Save full report JSON to KV alongside lead

worker/src/index.js — after line 369

// Save full report JSON to KV (separate key, larger payload)
// Uses same leadId for correlation. TTL: 1 year (reports are valuable long-term).
const reportPayload = {
  id: leadId,
  lead_id: leadId,
  timestamp: lead.timestamp,
  practice_url: practiceUrl,
  domain: domainSlug,
  vertical: vert,
  email: email,
  name: name || "Not provided",

  // Full report data
  report: report,

  // Metadata for dashboard listing without loading full report
  meta: {
    practice_name: report.practice_name,
    city: report.city,
    state: report.state,
    overall_score: report.overall_score,
    grade: report.grade,
    data_confidence: report.data_confidence,
    revenue_lost: report.revenue_lost_annually,
    category_scores: {
      gbp: report.categories?.gbp?.score,
      reviews: report.categories?.reviews?.score,
      ai_readiness: report.categories?.ai_readiness?.score,
      local_seo: report.categories?.local_seo?.score,
      content: report.categories?.content?.score,
      technical: report.categories?.technical?.score,
    },
    competitor_count: (report.competitors || []).length,
  },
};

// Non-blocking save — don't slow down the response
ctx.waitUntil(
  env.LEADS.put(`report_${leadId}`, JSON.stringify(reportPayload), {
    expirationTtl: 365 * 86400,  // 1 year retention
  })
);
KV Size Limit: Cloudflare KV values can be up to 25 MB. A typical audit report is 5-15 KB JSON — well within limits. No compression needed.

1B. Add API endpoint to list/fetch reports

worker/src/index.js — new route

// GET /reports — list all reports (metadata only, for dashboard listing)
// GET /reports/:leadId — get full report JSON
// Auth: same LEADS_SECRET bearer token

if (url.pathname === "/reports" && request.method === "GET") {
  // Auth check (same as /leads)
  if (!env.LEADS_SECRET || bearerToken !== env.LEADS_SECRET) {
    return new Response(JSON.stringify({ error: "Unauthorized" }), {
      status: 401, headers: { "Content-Type": "application/json" },
    });
  }

  // List all reports (metadata only — fast)
  const list = await env.LEADS.list({ prefix: "report_" });
  const reports = [];
  for (const key of list.keys) {
    const val = await env.LEADS.get(key.name, "json");
    if (val) {
      // Return metadata only (not full report) for listing performance
      reports.push({
        id: val.id,
        lead_id: val.lead_id,
        timestamp: val.timestamp,
        practice_url: val.practice_url,
        domain: val.domain,
        vertical: val.vertical,
        email: val.email,
        name: val.name,
        meta: val.meta,
      });
    }
  }
  reports.sort((a, b) => new Date(b.timestamp) - new Date(a.timestamp));
  return new Response(JSON.stringify(reports, null, 2), {
    headers: { "Content-Type": "application/json" },
  });
}

// GET /reports/:leadId — full report
const reportMatch = url.pathname.match(/^\/reports\/(lead_.+)$/);
if (reportMatch && request.method === "GET") {
  if (!env.LEADS_SECRET || bearerToken !== env.LEADS_SECRET) {
    return new Response(JSON.stringify({ error: "Unauthorized" }), {
      status: 401, headers: { "Content-Type": "application/json" },
    });
  }

  const reportKey = `report_${reportMatch[1]}`;
  const val = await env.LEADS.get(reportKey, "json");
  if (!val) {
    return new Response(JSON.stringify({ error: "Report not found" }), {
      status: 404, headers: { "Content-Type": "application/json" },
    });
  }

  return new Response(JSON.stringify(val, null, 2), {
    headers: { "Content-Type": "application/json" },
  });
}

2A. Database schema

geo_agent/db.py — new table

CREATE TABLE IF NOT EXISTS landing_page_reports (
    id              TEXT PRIMARY KEY,           -- same as KV lead_id
    lead_id         TEXT NOT NULL,              -- correlates to KV lead
    customer_id     TEXT,                       -- FK to customers (nullable, linked later)
    timestamp       TEXT NOT NULL,              -- ISO 8601
    practice_url    TEXT NOT NULL,
    domain          TEXT NOT NULL,
    vertical        TEXT DEFAULT 'dental',
    email           TEXT,
    contact_name    TEXT,
    practice_name   TEXT,
    city            TEXT,
    state           TEXT,
    overall_score   INTEGER,
    grade           TEXT,
    data_confidence TEXT,
    revenue_lost    TEXT,
    category_scores TEXT,                       -- JSON string of {gbp, reviews, ...}
    competitor_count INTEGER DEFAULT 0,
    full_report     TEXT,                       -- Full report JSON (large)
    synced_at       TEXT NOT NULL,              -- When dashboard pulled from KV
    FOREIGN KEY (customer_id) REFERENCES customers(id)
);

CREATE INDEX IF NOT EXISTS idx_lpr_domain ON landing_page_reports(domain);
CREATE INDEX IF NOT EXISTS idx_lpr_customer ON landing_page_reports(customer_id);
CREATE INDEX IF NOT EXISTS idx_lpr_timestamp ON landing_page_reports(timestamp DESC);
CREATE INDEX IF NOT EXISTS idx_lpr_email ON landing_page_reports(email);

2B. Sync function

dashboard/app.py — new function

import httpx

def sync_landing_page_reports(db):
    """Pull new reports from the CF Worker KV and store in SQLite.

    Called manually from dashboard or on a schedule.
    Idempotent — skips reports already synced (by id).
    """
    api_url = os.environ.get("PRACTICERANK_API_URL", "https://practicerank-api.practice-rank-ai-seo.workers.dev")
    api_secret = os.environ.get("LEADS_SECRET", "")
    if not api_secret:
        return {"error": "LEADS_SECRET not configured", "synced": 0}

    # Fetch report list from worker
    resp = httpx.get(
        f"{api_url}/reports",
        headers={"Authorization": f"Bearer {api_secret}"},
        timeout=30,
    )
    resp.raise_for_status()
    remote_reports = resp.json()

    # Get existing IDs to skip duplicates
    existing = {r["id"] for r in db.execute(
        "SELECT id FROM landing_page_reports"
    ).fetchall()}

    synced = 0
    for meta in remote_reports:
        if meta["id"] in existing:
            continue

        # Fetch full report for this lead
        full_resp = httpx.get(
            f"{api_url}/reports/{meta['lead_id']}",
            headers={"Authorization": f"Bearer {api_secret}"},
            timeout=30,
        )
        if full_resp.status_code != 200:
            continue

        full = full_resp.json()
        cat_scores = meta.get("meta", {}).get("category_scores", {})

        # Auto-link to existing customer by domain match
        customer_id = None
        domain_clean = (meta.get("domain", "") or "").replace("_", ".").lower()
        if domain_clean:
            match = db.execute(
                "SELECT id FROM customers WHERE LOWER(domain) = ? OR LOWER(url) LIKE ?",
                (domain_clean, f"%{domain_clean}%")
            ).fetchone()
            if match:
                customer_id = match["id"]

        db.execute("""
            INSERT INTO landing_page_reports
            (id, lead_id, customer_id, timestamp, practice_url, domain,
             vertical, email, contact_name, practice_name, city, state,
             overall_score, grade, data_confidence, revenue_lost,
             category_scores, competitor_count, full_report, synced_at)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
        """, (
            meta["id"], meta["lead_id"], customer_id,
            meta["timestamp"], meta.get("practice_url", ""),
            meta.get("domain", ""), meta.get("vertical", "dental"),
            meta.get("email", ""), meta.get("name", ""),
            meta.get("meta", {}).get("practice_name", ""),
            meta.get("meta", {}).get("city", ""),
            meta.get("meta", {}).get("state", ""),
            meta.get("meta", {}).get("overall_score"),
            meta.get("meta", {}).get("grade", ""),
            meta.get("meta", {}).get("data_confidence", ""),
            meta.get("meta", {}).get("revenue_lost", ""),
            json.dumps(cat_scores),
            meta.get("meta", {}).get("competitor_count", 0),
            json.dumps(full.get("report", {})),
            datetime.utcnow().isoformat(),
        ))
        synced += 1

    db.commit()
    return {"synced": synced, "total": len(remote_reports), "already_synced": len(existing)}

Security Considerations

  • Auth: Worker /reports endpoints use same LEADS_SECRET bearer token as existing /leads endpoint
  • PII: Reports contain email addresses and phone numbers. Dashboard is already behind login. KV data has 1-year TTL.
  • Size: Full report JSON is ~5-15 KB. KV limit is 25 MB. SQLite handles this fine.
  • Rate limiting: Sync is manual (button click) or scheduled (cron). Not exposed publicly.
  • No secrets in reports: Report JSON never contains API keys — only practice data and scores.
